# Стартиране с AstroArchive.exe

Разархивирай целия Windows пакет в отделна папка и отвори `AstroArchive.exe`.
Това е единственият потребителски стартер. Останалите файлове в пакета са
необходими; `.exe` файлът не е самостоятелно копие на цялата програма.
Не са нужни `Setup.cmd`, `Start.cmd`, глобален Python или администраторски права.
Изборът на папки и файлове използва Windows диалози през същия `.exe`;
вградената Python среда няма нужда от Tcl/Tk.

Екранът показва логото, Слънцето, Земята и Луната. Земята обикаля около
Слънцето, Луната около Земята, а комета с опашка отбелязва етапите на подготовка.
Индикаторът показва напредъка по проверки, а не процент изтеглени байтове.

## Проверки и изтегляне

1. Проверява се наличието на необходимите програмни файлове. Само липсващи
   файлове спират старта. Редакции на налични файлове не са нова версия и не
   изискват възстановяване. „Към изданията“ отваря официалната страница в GitHub.
2. Проверява се собствената Python среда в `.runtime/python/`, точните версии
   от `requirements-lock.txt` и действителното зареждане на основните библиотеки.
3. При липси изтеглянето започва само след натискане на „Изтегли“.
   Python 3.13.9 x64 идва от python.org; pip 25.3 и библиотеките — от PyPI.
   SHA-256 на pip wheel се проверява спрямо HTTPS метаданните на PyPI.
   Python ZIP се изтегля през HTTPS; няма отделно закрепена SHA-256 за него.
   Изтеглят се само готови binary wheels, без компилиране на чужд изходен код.
4. Средата се подготвя в отделна временна папка и се активира само ако премине
   проверките. Предишна среда се запазва за възстановяване.
5. Проверяват се публикуваните GitHub Releases, включително предварителните
   издания. Непубликувани промени в основния клон не са обновяване.

При ново издание има три избора: „Изтегли новата версия“, „Пропусни сега“ и
„Пропусни версията“. В Beta 1.2.1 бутонът изтегля официалния Windows x64 ZIP
директно, с напредък и проверка на размера и SHA-256 от GitHub. Пакетът се
запазва в `Backend/Cache/data/Updates/`, която се създава само при изтегляне.
Има спиране и повторен опит; непълните временни файлове се премахват.
След завършване „Отвори папката“ показва проверения ZIP. Разархивирай го в
отделна папка. Текущата инсталация и личните данни не се презаписват.
Пропускането на версия се запазва само за тази инсталация.
Без интернет подготвено копие може да стартира; първата инсталация изисква връзка.

Същото директно изтегляне е достъпно в **Настройки → Диагностика**, след
проверка за нова версия. Работи като фонова задача и може да бъде спряно.
Старите публикувани Beta 1.1/1.2 запазват старото си поведение; за първото
преминаване към Beta 1.2.1 използвай нейния Windows ZIP от Releases.

## Независими копия

Всяка папка има отделни Python библиотеки, кеш, настройки, каталог, сървърен
порт, случаен RPC ключ и браузърен профил в Edge. Идентичността на инсталацията
се изчислява от каноничния път. Съществуващ сървър се използва само ако върне
същата идентичност. Заглавията на прозорците също съдържат кратък идентификатор.
Две папки могат да работят едновременно; повторно отваряне на една папка
активира нейното работещо копие. Данни се споделят само ако потребителят
изрично избере една и съща външна архивна папка или услуга за споделяне.

## Компилиране и преглед

```powershell
./Tools/build_launcher.ps1
./AstroArchive.exe --preview
./AstroArchive.exe --render publication-review/launcher-preview.png
./AstroArchive.exe --self-test
```

Компилирането използва Windows .NET Framework C# компилатора. Изходният код е
в `Tools/Launcher/Launcher.cs`; компилираният `.exe` остава локален до изрично
одобрено издание. Пакетът за Windows се подготвя от чистото allowlist копие чрез
`Tools/prepare_publication.py --core-only`, след което стартерът се компилира
в самото чисто копие. Не се добавят `.runtime`, лични данни или инсталирани плъгини.

При издаване подай `-ReleaseCutoff` с UTC датата на това издание,
`-ReleaseTag` с точния му таг и `-ReleaseId` с неговото GitHub ID, ако е известно.
Това предотвратява известяване за същото
издание. Преди качване тествай реалното изтегляне на всички заключени библиотеки,
две едновременно пуснати копия и стартиране без интернет.
Съществуващият таг `beta1` и неговите файлове не се заменят от тези инструменти.
