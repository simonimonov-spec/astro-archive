# Изключение за GitHub

Изключението за правата по условията на GitHub е включено в [лиценза за ядрото](../LICENSE.txt). То признава приложимите права за хостване, разглеждане, копиране и форкване чрез функциите на платформата, без да предоставя допълнителни права за друго брандиране или повторно публикуване извън предвиденото в условията и приложимото право.

Източници:

- [GitHub Terms of Service — License Grant to Other Users](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#5-license-grant-to-other-users)
- [GitHub Docs — Licensing a repository](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
