# Лиценз и GitHub

За ядрото на Astro Archive, SDK и примерния плъгин е избран [лицензът MIT](../LICENSE.txt). Той разрешава използване, промени, разпространение и продажба при запазване на известието за авторско право и текста на лиценза. Не е необходимо отделно изключение за GitHub fork.

Независимите съществуващи плъгини не се прелицензират. Правата на трети страни остават в сила.
