# Плъгини от GitHub

Чистата програма няма инсталирани плъгини и няма папка `Plugins`.
При първото инсталиране тя се създава автоматично. След изтриване на
последния плъгин празната папка се премахва. Непознати файлове в нея
не се изтриват автоматично.

## Изтегляне, включване и изтриване

1. Отвори **Настройки → Плъгини**. Виждат се инсталираните и наличните в GitHub добавки.
2. Избери добавка и **Изтегли от GitHub**. Изтеглянето проверява точния commit,
   SHA-256 на ZIP, идентификатора и версията. Плъгинът остава изключен.
3. Прегледай описанието и разрешенията, включи добавката и разреши интерфейса ѝ.
4. В края на описанието са версията и бутонът за изтриване. Кодът се премества
   извън `Plugins`, в локалния кеш `RemovedPlugins`, а настройките се запазват.

Каталогът се проверява при стартиране. Бутонът **Провери каталога и версиите
в GitHub** проверява отново. Офлайн се показва запазеният каталог с обяснение.
Нова версия не се инсталира автоматично: изтрий старата и изтегли новата.
Инсталиране върху съществуващ идентификатор се отказва. След промяна на кода
плъгинът трябва да бъде включен отново.

## Публични добавки

Всеки плъгин е в собствен клон `plugin-<id>` на официалното хранилище.
Основният клон и основният пакет не съдържат тези добавки.
Отделните GitHub ZIP изтегляния са фиксирани към commit от каталога;
това не създава и не променя Release на основната програма.

| Плъгин | Версия | Изходен код |
| --- | --- | --- |
| Справка по обекти | V-1 | [archive-overview](https://github.com/simonimonov-spec/astro-archive/tree/plugin-archive-overview) |
| AI оценител | Beta-1 | [frame-inspector-ai](https://github.com/simonimonov-spec/astro-archive/tree/plugin-frame-inspector-ai) |
| Автоматично стакване чрез Siril | V-1 | [siril-auto](https://github.com/simonimonov-spec/astro-archive/tree/plugin-siril-auto) |
| Remote Operation | V-1 | [remote-operation](https://github.com/simonimonov-spec/astro-archive/tree/plugin-remote-operation) |
| Shared Archives · LAN | V-1 | [shared-archives](https://github.com/simonimonov-spec/astro-archive/tree/plugin-shared-archives) |
| IASC Campaigns | V-1 | [iasc-campaigns](https://github.com/simonimonov-spec/astro-archive/tree/plugin-iasc-campaigns) |

AI Trainer и частният плъгин за етикетиране `ai-training` не се публикуват.
AI оценителят работи без Trainer. Без активен обучен модел използва евристики;
лични модели, FITS, учебни набори и настройки не са включени.

## Допълнителни изисквания

Основните зависимости са достатъчни за евристичния AI режим. За ResNet
инсталирай отделно `requirements-ai.txt` или `requirements-gpu.txt` от папката
на оценителя в Python средата на приложението. Това не става автоматично.
Siril изисква собствена инсталация на Siril CLI. IASC изисква разрешен достъп
и зависимостите в README на плъгина. Дистанционният достъп изисква HTTPS и
доверен сертификат, а LAN архивите — Windows SMB и съответните права.

За ръчна инсталация изтегли ZIP на избрания клон, разархивирай и използвай
**Добави плъгин…** с папката, съдържаща `plugin.json`.
Плъгините изпълняват локален Python код; SDK разрешенията не са системна изолация.

## Версия на програмата

При стартиране се проверяват официалните GitHub Releases. В **Настройки →
Диагностика → Провери за нова версия** проверката се пуска ръчно.
Стартерът предава идентификатора и датата на инсталираното издание.
При директно стартиране на изходния код няма надежден идентификатор на издание:
показва се последното публикувано издание без твърдение, че копието е актуално.
Изтеглянето на нова програма става от Releases и не заменя текущите данни.
