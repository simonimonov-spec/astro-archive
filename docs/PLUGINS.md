# Отделно изтегляне и управление на плъгините

Основният пакет не съдържа инсталирани плъгини или AI зависимости.
Всеки плъгин е отделно хранилище и отделна папка с `plugin.json`.
Имената на хранилищата по-долу са **подготвени локални имена**.
Публичните адреси ще бъдат добавени след потвърждение и публикуване;
не са измисляни потребител или GitHub адреси.

| Плъгин / име на хранилище | Функция | Допълнителни изисквания |
| --- | --- | --- |
| `archive-overview` / `astro-archive-plugin-archive-overview` | Справка по обекти, таблица и диаграма | Само основните зависимости |
| `frame-inspector-ai` / `astro-archive-plugin-frame-inspector-ai` | AI/евристични оценки, набори и включен `Trainer/` | Евристичният режим използва основните зависимости; ResNet изисква отделно PyTorch; Trainer използва Tkinter |
| `ai-training` / `astro-archive-plugin-ai-training` | Ръчни етикети в прегледа | Инсталиран и включен `frame-inspector-ai`, възможност `inspector.training.v1` |
| `siril-auto` / `astro-archive-plugin-siril-auto` | Автоматично стакване | Собствена отделна инсталация на Siril CLI; посочи нейния `siril-cli.exe` в настройките |
| `remote-operation` / `astro-archive-plugin-remote-operation` | Дистанционен интерфейс с HTTPS | Windows, доверен TLS сертификат; за описания VPN режим — собствен Tailscale. Виж README на плъгина |
| `shared-archives` / `astro-archive-plugin-shared-archives` | LAN архиви | Windows SMB 3 с шифроване, права за избрания ресурс и мрежова връзка |
| `iasc-campaigns` / `astro-archive-plugin-iasc-campaigns` | Кампании и Image Sets | Собствен разрешен IASC достъп; Edge и Windows DPAPI за вход; отделни Python зависимости по-долу |

Версиите и разрешенията се четат от съществуващите `plugin.json` файлове.
Плъгините работят чрез общия Bridge SDK и не са самостоятелни приложения.

## Инсталиране на всеки плъгин

1. Отвори съответното хранилище → **Code → Download ZIP**.
2. Разархивирай ZIP. В изтеглената папка намери `plugin.json`.
3. В Astro Archive отвори **Настройки → Плъгини → Инсталирай** и избери точно
   папката, съдържаща този файл. Това работи и ако GitHub е добавил `-main`
   към името на изтеглената папка. Програмата копира кода в `Plugins/<id>/`.
4. Прегледай кода и заявените разрешения. Включи плъгина и разреши
   визуализацията му, ако искаш неговите контроли в интерфейса.

Алтернатива при затворено приложение: копирай съдържанието в папка с точно
име `Plugins/<id>/`, например `Plugins/siril-auto/plugin.json`. После отвори
програмата и обнови списъка на плъгините. Не създавай двойна вложеност
`Plugins/<id>/<repository>-main/plugin.json`.

Плъгините изпълняват локален Python код. Разрешенията в интерфейса управляват
SDK достъпа, но не са изолация на Python от операционната система.

## Отделни Python зависимости

Изпълнявай командите от папката на **Astro Archive**, след инсталиране на
съответния плъгин. Основният `Setup.cmd` не изпълнява тези команди.

За ResNet/AI Trainer използвай един от двата съществуващи файла:

```powershell
.\.venv\Scripts\python.exe -m pip install -r Plugins/frame-inspector-ai/requirements-ai.txt
# Алтернатива за NVIDIA CUDA, при съвместим драйвер:
.\.venv\Scripts\python.exe -m pip install -r Plugins/frame-inspector-ai/requirements-gpu.txt
```

Няма включени лични обучени модели или наблюдения. Съществуващият `model.json`
описва синтетичен начален модел с `realArchiveFrames: 0`; активни обучени
модели и учебни набори от локалния кеш не се разпространяват.
AI Trainer се отваря от плъгина, който му подава временна сесия през pipe.
Вече се намира в `Plugins/frame-inspector-ai/Trainer/`.

За прозореца за вход в IASC:

```powershell
.\.venv\Scripts\python.exe -m pip install -r Plugins/iasc-campaigns/requirements.txt
```

Алтернатива: `Plugins/iasc-campaigns/Install Login Support.cmd`.
За незадължителния ADES износ:

```powershell
.\.venv\Scripts\python.exe -m pip install -r Plugins/iasc-campaigns/requirements-export.txt
```

Другите изброени плъгини нямат отделен Python requirements файл в изходния
проект. Изискваните външни програми не се включват в изтеглянията.

## Обновяване

1. Изчакай задачите на плъгина и затвори програмата. Направи резервно копие на
   `Backend/Cache/data/Plugins/<id>/` и на стария код.
2. Изтегли новия ZIP. Замени **цялата** папка `Plugins/<id>/` с новото
   съдържание; не смесвай стари и нови файлове. Запази личните данни в кеша.
3. Ако requirements файлът е променен, инсталирай го отново в `.venv`.
4. Стартирай Astro Archive, обнови списъка, прегледай променения код и
   разрешения и включи плъгина отново. Променените файлове автоматично
   отменят старото включване и разрешение за интерфейс.

Може да използваш и **Премахни**, после **Инсталирай** с новата папка.
Инсталиране върху съществуващ ID се отказва, за да няма тихо презаписване.

## Изключване и премахване

Изключването в Настройки → Плъгини спира плъгина и скрива неговите контроли.
**Премахни** премества кода в `Backend/Cache/data/RemovedPlugins/`;
настройките и учебните данни остават локално в кеша. За пълно изтриване първо
затвори програмата, направи нужното резервно копие и изтрий само съответната
папка с данни и запазеното копие на кода. Не изтривай целия кеш или архивите.
Изключването/премахването не деинсталира споделените Python библиотеки.

## Откриване и проблеми

`Bridge/Plugins/manager.py` сканира преките подпапки на `Plugins`, проверява
`apiVersion: 1`, ID, входния файл, UI договора и разрешенията. Не импортира
код при самото откриване. Всеки плъгин се зарежда в отделно Python пространство
при включване; грешка в един плъгин не спира откриването на останалите.
Промененият код изисква ново потвърждение. Подробности се показват в списъка.

При празна папка програмата работи с основните си функции. Ако AI Training
е включен без AI оценителя, опитът за оценка показва липсващата възможност;
инсталирай и включи `frame-inspector-ai`. При липсващ модул виж README на
конкретния плъгин и инсталирай неговите зависимости в `.venv` на програмата.
