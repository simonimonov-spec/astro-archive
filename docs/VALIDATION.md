# Проверки при подготовката за GitHub

Изпълнените автоматични проверки са за кода и отделянето на пакетите.
Те не потвърждават пълен потребителски старт от чист Windows компютър.

## Потвърдено

Новият набор съдържа 10 теста: 9 успешни и 1 пропуснат интеграционен тест.
Същият набор е изпълнен и от чистото основно копие без инсталирани плъгини.
Проверен е Python синтаксисът на 115 файла и JavaScript синтаксисът на 32
основни UI файла. Седемте отделно изнесени плъгина са инсталирани чрез
истинския folder installer в изолиран временен каталог, без включване на кода.
Проверени са съдържанието, JSON файловете и SHA-256 хешовете на осемте ZIP пакета.

- Откриване с празна папка Plugins; разбираеми грешки за липсващи функции.
- Откриването не изпълнява Python кода на плъгините.
- Невалиден или неуспешно включен плъгин не блокира останалите.
- Включване и извикване на функция; промяна на код отменя включването и UI разрешението.
- Инсталиране от папка с GitHub име, отказ на дублиран ID, премахване със запазени локални данни.
- Валидиране на наличните седем манифеста.
- Отделни пакети и включен Trainer само в AI оценителя.
- Отказ на FITS, кеш, credentials файлове и излизане извън разрешените пътища при пакетиране.
- Проверка на публичните текстови файлове за разпознаваеми токени, частни ключове,
  credential URL адреси и лични Windows пътища, без отпечатване на стойности.
- Синтактична проверка на Python кода. Личният кеш не е използван за тестове.

## Ограничения на средата

Наличната проектна `.venv` препраща към Python 3.13 от Microsoft Store,
който не се стартира от изпълняващата среда. Тестовете за плъгин lifecycle
и пакетиране използваха отделния наличен Python 3.12.
Той няма SciPy, Astropy и Photutils. Опитът за изтегляне на зависимостите
не успя поради недостъпна DNS/мрежа към PyPI.

Пълният интеграционен тест `CoreIntegrationTests` е пропуснат с явна причина.
Съществуващите научни тестове на AI оценителя не могат да се изпълнят в тази
среда поради липсващ SciPy. Няма потвърждение за пълния GUI, Siril, GPU,
IASC вход, HTTPS/VPN или SMB работа след разделянето.
Запазените requirements версии не са заменяни с предполагаеми други версии.

## Оставаща проверка преди публикуване

На Windows компилирай стартера с `Tools/build_launcher.ps1` в чистия основен пакет,
отвори `AstroArchive.exe`, позволи изтеглянето на компонентите,
стартирай без плъгини и провери архив/FITS преглед/стандартен анализ.
Инсталирай плъгините поотделно и провери всяка нужна външна интеграция.
За научните тестове първо инсталирай основните зависимости; ResNet тестовете
изискват и изрично инсталиран PyTorch. При тестове, които покриват общите
AI етикети, инсталирай и `ai-training`.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m unittest discover -s Plugins/frame-inspector-ai/tests -v
```
