ПЛЪГИНИ — Astro Archive · API 1

Всяка добавка е отделна папка: Plugins/<id>/plugin.json и собствен Python код.
„Обнови“ в Настройки → Плъгини проверява папките, без да изпълнява изключен код.
Първо включи добавката, после отделно разреши заявените ѝ визуални полета.
Промяна на кода или ресурсите изисква повторен преглед и включване.

archive-overview е работещ, изключен по подразбиране пример „Справка по обекти“.
Добавя таблица, диаграма и свои настройки чрез готовите визуални команди.
Няма нужда да редактираш основния код, за да добавиш друг такъв плъгин.

Места за визуализация: archive, analysis, analysis-tools, preparation, settings,
customization, header.
Компоненти: text, metric, input, number, checkbox, select, button, table, chart,
group, console, image.
В основния интерфейс произволен HTML, JavaScript и CSS не се изпълняват; визуалните
полета минават през фиксирания декларативен договор. Remote Operation има отделен
HTTPS клиент със собствени страници.
Налични диаграми: линия, точки и колони; сложни собствени графични компоненти
изискват бъдещо разширяване на договора.

Основният Python код може да открива и извиква именувани plugin capabilities.
Настройките на добавката се пазят в Backend/Cache/data/Plugins/<id>/settings.json.
При премахване папката се прибира в кеша RemovedPlugins; настройките се пазят.

Python добавките изпълняват собствен код в процеса на приложението. Разрешенията
ограничават командите през SDK, но не са изолация на Python от Windows.
Включвай добавки само от източници, на които се доверяваш.

siril-auto и remote-operation са самостоятелни Python плъгини и се зареждат през
Bridge; старият C# UI път не се използва.
